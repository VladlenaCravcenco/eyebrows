# Видео-презентация Mentor

Продающий ролик ~83 секунды на английском, в стиле презентаций Apple, в двух форматах. Собран в [Remotion](https://www.remotion.dev) из настоящих экранов английской версии приложения.

Готовые видео:
- `out/mentor-keynote-16x9.mp4` — 1920×1080, для встреч, сайта, YouTube
- `out/mentor-keynote-9x16.mp4` — 1080×1920, для сторис, Reels, TikTok

## Пересобрать

```bash
cd presentation
npm install
npx playwright install chromium   # один раз

# 1. Запустить английскую версию приложения (в корне проекта)
#    VITE_LANG=en VITE_BRAND_NAME=Mentor npx vite --port 5191
#    и снять свежие экраны:
APP_URL=http://localhost:5191 npm run screens

# 2. Посмотреть и подправить ролик в браузере
npm run studio

# 3. Отрендерить MP4
npm run render            # 16:9
npm run render:vertical   # 9:16
```

- Сценарий, тексты и длительность сцен — `src/Keynote.tsx` (список `scenes` внизу файла).
- Телефон, шрифт, анимация появления текста, мок чата Telegram — `src/kit.tsx`.
- Какие экраны снимаются и с каким прогрессом — `scripts/capture.mjs`.

## Звук

Весь звук синтезирован кодом — без сэмплов и чужой музыки, поэтому никаких проблем с правами:
щелчки на появлении текста, «вжух» на переходах, «поп» на плашках, удары на логотипе и в финале,
звуки правильного/неправильного ответа, конфетти, набор текста и тихая атмосферная подложка.

- Пересоздать звуки: `node scripts/sfx.mjs` (файлы в `public/sfx/`).
- Где и с какой громкостью звучат — список `scenes` в `src/Keynote.tsx` (третий элемент каждой сцены), общий уровень — `GAIN`.
