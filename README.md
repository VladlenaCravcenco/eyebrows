# Eyebrows.curs — обучение мастеров

Мини-приложение для новых сотрудниц студии: короткие уроки, чек-листы, мини-тесты,
прогресс, достижения и база знаний. Открывается как обычный сайт на телефоне
(можно «Добавить на экран Домой») и как Telegram Mini App внутри бота.

## Запуск

```bash
npm install
npm run dev      # откроется на http://localhost:5173 (и в локальной сети — для теста с телефона)
npm run build    # готовая сборка в папке dist/
```

## Где править тексты

**В самом приложении** (для руководителя): бот → «Обучение» → Профиль → «Режим руководителя» →
«Курсы и тексты». Там можно менять курсы, уроки, вопросы тестов и базу знаний, добавлять,
удалять и менять порядок. Правки копятся в черновике и видны девочкам после «Сохранить для всех».
Сохранённая версия хранится в базе (Upstash), предыдущая — в ключе `content:prev` на случай отката.

Начальные тексты (пока в базе ничего не сохранено) лежат в `src/content/courses.ts`
и `src/content/knowledge.ts`. Название студии — `src/content/brand.ts`.

## Как устроено

- Уроки открываются по очереди, тест — после всех уроков курса. Тест засчитан при ≥ 60% верных
  (`PASS_THRESHOLD` в `courses.ts`).
- В чек-листе нужно отметить все пункты, чтобы пройти дальше.
- Прогресс, серия дней и достижения считаются автоматически.
- Внутри Telegram прогресс сохраняется на сервере (`server/`), руководитель видит реальную команду.
  В обычном браузере — только на телефоне, а режим руководителя показывает демо.

## Сервер и бот (`api/`) — функции Vercel

- `api/me.js`, `api/progress.js` — вход по подписи Telegram и сохранение прогресса;
- `api/team.js`, `api/role.js` — команда и должности (только руководитель);
- `api/content.js` — тексты курсов и базы знаний: читают все, сохраняет только руководитель;
- `api/bot.js` — бот (вебхук): на `/start` присылает кнопку «Открыть обучение», `/myid` — свой Telegram ID;
- `api/setup.js` — открыть один раз после деплоя, подключает бота к сайту;
- `api/cron.js` — каждый день в 09:00 UTC (11:00 по Кишинёву зимой) напоминает тем, кто не заходил 2+ дня.

Данные хранятся в Upstash Redis (бесплатный тариф, подключается из Vercel).

## Подключение — по шагам

1. **Бот.** @BotFather → `/newbot` → имя и адрес (на `bot`) → скопируйте токен.
2. **Vercel → Add New → Project** → импорт репозитория `eyebrows` → Deploy (настройки по умолчанию).
3. **Storage → Create Database → Upstash (Redis)** → бесплатный план → Connect к проекту.
4. **Settings → Environment Variables:**
   - `BOT_TOKEN` — токен из BotFather;
   - `CRON_SECRET` — любая длинная случайная строка;
   - `MANAGER_IDS` — пока пусто (см. шаг 7).
5. **Deployments → ⋯ → Redeploy**, чтобы применились переменные.
6. Откройте `https://<ваш-проект>.vercel.app/api/setup` — должно появиться «Бот подключён ✅».
7. Напишите боту `/myid`, впишите число в `MANAGER_IDS`, снова Redeploy.
8. **Девочкам** отправьте ссылку `https://t.me/<адрес_бота>`.
